# Scope Guard 授权纪律（yotta-recon）

> 本文件说明 yotta-recon 内建授权纪律的实现方式与使用姿势。
> 原则：**未授权目标默认拒绝**。侦察是安全测试的起点，也是法律风险最高的环节之一；
> 未经授权扫描他人系统违反《网络安全法》与《刑法》第 285/286 条，后果由使用者承担。

## 一、五道防线落地

| 防线 | 落地方式 |
|---|---|
| 1. Scope Guard 硬机制 | 引擎在扫描前对全部目标做授权判定；未授权目标默认拒绝，绝不静默放行 |
| 2. 默认合法靶场 | 文档示例一律用 127.0.0.1 / localhost / 私有测试网段；真实目标须显式授权 |
| 3. 授权声明机制 | --scope 文件声明授权范围；或 --assume-authorized --yes 显式声明已获授权 |
| 4. 法律声明 | 引擎交互确认提示 + README/SKILL 法律条款 |
| 5. 响应预案 + 留痕 | 每次扫描生成 scan_id，报告含时间/目标/授权来源；发现风险只提示、不利用 |

## 二、放行规则（满足其一）

1. **回环地址**（127.0.0.0/8、::1、localhost）：本机自测默认放行，无需授权声明。
2. **授权范围文件**（--scope）：文件每行一个目标，支持 IP / CIDR / 主机名，# 开头为注释。
   示例 scope.txt：

   # 授权测试目标
   192.168.1.0/24
   10.0.0.5
   lab.example.com

3. **显式授权声明**（--assume-authorized --yes）：用户确认目标已获授权并跳过交互确认。
   仅用于有书面/口头授权的场景；AI 智能体无交互能力时用此方式需谨慎。

其余目标（公网 IP、未授权私有地址、保留地址、链路本地等）默认拒绝，退出码 3。

## 三、使用姿势（AI 智能体）

1. **先预检**：python3 scripts/yotta_recon.py check-scope --targets <目标> [--scope <file>]
   - 全部 ALLOW 才继续；出现 DENY 先补授权，不要绕过。
2. **再扫描**：

   # 有授权范围文件
   python3 scripts/yotta_recon.py scan --targets <目标> --scope scope.txt --yes

   # 用户明确声明已授权
   python3 scripts/yotta_recon.py scan --targets <目标> --assume-authorized --yes

3. **报告**：--report report.md 生成 Markdown 报告，报告含 scan_id / 时间 / 授权来源（操作留痕）。

## 四、交互确认

人类直接运行且未带授权声明时，扫描非回环目标会弹出确认提示，输入 y 继续。
AI 场景（无终端输入）会直接拒绝并返回退出码 3，避免误扫。

## 五、风险提示纪律

- 已知风险提示（如 ProFTPD 1.3.5 / vsftpd 2.3.4）仅为**版本指纹匹配**，不代表目标确实存在漏洞；
- 报告措辞为「请人工核实」，不提供利用细节；发现风险后先人工复核再处置。
